# 💼 Информационная система поддержки принятия решений в HR-Tech
> **Тема проекта:** Проектирование информационной системы поддержки принятия решений (СППР) при управлении человеческим капиталом.

---

## 📌 1. Актуальность проекта

Современный рынок труда сталкивается с существенным ростом затрат на рекрутмент и рисками неэффективного подбора:
* **Рост стоимости привлечения:** Постоянное увеличение показателя *Cost-per-Hire* (стоимость закрытия одной вакансии).
* **Риски текучести:** Прямые и косвенные финансовые потери бизнеса от раннего ухода новых сотрудников на этапе адаптации и испытательного срока.

---

## 🎯 2. Цель проекта

Комплексная автоматизация первичного скрининга кандидатов и предиктивная оценка рисков их раннего увольнения на основе анализа данных резюме и профилей вакансий.

---

## ⚙️ 3. Функциональные требования

Система включает в себя три ключевых функциональных модуля:

### 🔍 3.1. Интеллектуальный парсинг и матчинг (NLP)
* Извлечение сущностей и структурирование данных из неструктурированных резюме.
* Семантическое сопоставление (*matching*) профиля соискателя с формальными и неформальными требованиями вакансии.

### 🧠 3.2. Ранжирование с объяснимым ИИ (Explainable AI / XAI)
* Алгоритмическое распределение кандидатов по степени релевантности.
* Прозрачная аргументация скоринга: автоматическое формирование списка ключевых факторов соответствия и несоответствия для каждого кандидата.

### 📊 3.3. Рабочее место HR-менеджера (UI/UX)
* Интуитивный дашборд с визуализацией воронки подбора персонала.
* Инструменты фильтрации, групповой обработки и перехода по стадиям найма.

---

## 📈 4. Экономическое обоснование

Внедрение системы ориентировано на повышение операционной эффективности HR-департамента:

| Метрика | Ожидаемый эффект | Механизм достижения |
| :--- | :--- | :--- |
| **Time-to-Hire** | ⬇️ Существенное сокращение цикла | Устранение рутины на этапе первичного скрининга и скоринга резюме |
| **Recruitment Budget** | 💰 Прямая экономия средств | Снижение затрат на внешние каналы поиска и уменьшение потерь от ранней текучести |
| **Cost-per-Hire** | 📉 Оптимизация показателя | Рост конверсии кандидатов на финальных стадиях интервью |

---

## 🛠️ Предполагаемый стек технологий *(черновик)*
* **NLP & ML:** Python (spaCy, Transformers, Scikit-learn, SHAP/LIME для XAI)
* **Backend:** FastAPI / Django / Node.js
* **Frontend:** React / Vue.js
* **Database:** PostgreSQL / Vector DB (Qdrant / Milvus / ChromaDB)
